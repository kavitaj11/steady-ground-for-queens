# Steady Ground for Queens

**A moment to reflect. One step to take.**

What do you do when a decision feels tangled, the demands at home are piling up, or you’re ready for a new direction at work? Steady Ground for Queens gives you a place to start. Choose a practical prompt, explore the Bhagavad Gītā, or spend a few minutes on a puzzle that makes you think differently.

[**Open Steady Ground for Queens on GitHub Pages**](https://kavitaj11.github.io/steady-ground-for-queens/)

### Try a puzzle

In [Queens’ Gambits](https://kavitaj11.github.io/steady-ground-for-queens/#queens-gambits), play through 12 chess positions and see why the queen’s chase, fork, or sacrifice works. In [Maze Explorer](https://kavitaj11.github.io/steady-ground-for-queens/#maze-puzzles), drag the marker through ordered checkpoints, then compare your path with a step-by-step shortest route.

## Run locally

The app uses HTML, CSS, and JavaScript. From the repository root, serve the `dist/` folder with a local HTTP server.

```bash
python3 -m http.server 8000 --directory dist
```

Open [localhost:8000](http://localhost:8000). The [GitHub Pages workflow](.github/workflows/pages.yml) publishes the same folder.
